Stack Buffer Overflow Explorer

A teaching model of a 32-bit stack frame. Memory addresses increase downward in the grid. Nothing here runs real code; it only simulates byte writes.

void greet(char *input) {
  char buf[8];
  strcpy(buf, input);   // no length check
}
Stack frame (colors: buffer, canary, saved frame pointer, return address; red = changed from original)

Key ideas. C strings end with a NUL byte, so strcpy writes length + 1 bytes, which makes the classic off-by-one. Writes move toward higher addresses, which is exactly where the saved frame pointer and return address live. Defenses: bounds checking (fix the bug), canaries (detect corruption before returning), and others like ASLR and non-executable stacks that are not modeled here.
